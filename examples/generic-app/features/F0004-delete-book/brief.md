# Brief — Delete book

## Source

- Ticket: BOOK-4
- Author: Product owner

## Raw description

Readers need to remove books they no longer own. Deleting should ask for
confirmation. After deletion the book disappears from the list. If the book is
already gone, show a clear message.

## Known constraints

- No accounts, so the reader can delete any book in the library.
- No bulk delete.

## Acceptance ideas

- Confirmation before delete.
- Book disappears from the list.
- Missing book shows a clear message.
